# scripts de automação para o TFWR

# o que é The Farmer Was Replaced?

* The Farmer Was Replaced é um jogo de automação onde seu objetivo é programar com python um drone fazendeiro, a única maneira do drone se mexer é por scripts feitos pelo próprio jogador 
* a progressão se baseia em conseguir recursos para desbloquear novos códigos (como for, while, if) e novas plantas que requerem situações cada vez mais complexas, fazendo assim uma linha de aprendizagem
* o jogo pode ser comprado na Steam

# como rodar

* o jogo contém um terminal próprio do jogo, basta copiar e rodar o código
* os códigos estão em ordem de progressão natural do jogo
* alguns códigos podem não funcionar no começo do jogo por ter funções ainda não desbloqueadas como def(x):
* não existe um código pra arbustos pelo fato de a árvore ser mais eficiente em conseguir madeira
